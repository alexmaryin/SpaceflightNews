SpaceNews Explorer

Explore The Universe Compose Multiplatform App

Discover the latest space news from trusted sources including NASA, EASA, European Spaceflight, SpaceNews,Ars Technica, and more. With full-text search and local favorites, stay updated on space exploration anytime, anywhere.

Get it on Google Play View on GitHub

Features

Multiplatform

Native Android and Desktop applications built with Jetpack Compose Multiplatform. One codebase, amazing performance on all platforms.

Advanced Search

Full-text search across all sources. Find articles instantly by topic, author, or keyword.

Favorites

Save your favorite articles locally with Room database. Access them offline anytime.

Dark Mode

Built-in dark mode support with system-aware theme switching. Read comfortably in any lighting.

Lightning Fast

Paging library integration for smooth, efficient scrolling through thousands of articles.

CORS Support

Works with Ktor HTTP client and supports Content Security Policy for secure data fetching.
