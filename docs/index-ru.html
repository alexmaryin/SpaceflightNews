SpaceNews Explorer

Исследуйте Вселенную Мультиплатформенное приложение

Узнавайте последние новости космонавтики из проверенных источников: NASA, EASA, European Spaceflight, SpaceNews, Ars Technica и других. Полнотекстовый поиск и сохранение избранного прямо на устройстве — будьте в курсе космических событий в любое время и в любом месте.

Возможности

Мультиплатформенность

Нативные приложения для Android, десктопа и iOS на базе Jetpack Compose Multiplatform. Одна кодовая база — великолепная производительность на всех платформах. Приложение для iOS готово (скоро в App Store).

Расширенный поиск

Полнотекстовый поиск по всем источникам. Находите статьи мгновенно по теме, автору или ключевому слову.

Избранное

Сохраняйте любимые статьи локально в базе данных Room. Доступ к ним в любое время без подключения к интернету.

Тёмная тема

Встроенная тёмная тема с автоматическим переключением по системным настройкам. Читайте комфортно при любом освещении.

Молниеносная скорость

Интеграция с библиотекой Paging для плавной и эффективной прокрутки тысяч статей.

Поддержка CORS

Работает с HTTP-клиентом Ktor и поддерживает Content Security Policy для безопасной загрузки данных.
