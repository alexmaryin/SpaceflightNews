Политика конфиденциальности

Последнее обновление: 8 мая 2026 г.

1. Сбор информации

SpaceNews Explorer не собирает, не хранит и не передаёт никакие персональные данные. Приложение спроектировано с принципом конфиденциальности в своей основе.

  • Не собирается персональная идентификационная информация
  • Не отслеживаются данные о местоположении
  • Не ведётся аналитика поведения пользователей
  • Не используются cookies и отслеживающие скрипты

2. Обработка данных

Вся обработка данных происходит локально на вашем устройстве. Приложение использует следующие локальные сервисы:

  • Локальная база данных: Избранные статьи хранятся в базе данных Room только на вашем устройстве
  • Офлайн-хранилище: Кэшированные статьи сохраняются локально для чтения без интернета
  • Настройки: Пользовательские настройки (тема и др.) хранятся в Android DataStore

3. Использование данных API

Приложение загружает новости космонавтики из The Spaceflight News API (SNAPI), управляемого The Space Devs. Наше приложение:

  • Не изменяет ответы API
  • Не сохраняет пользовательские запросы или историю поиска
  • Не связывает запросы к API с личностью пользователя
  • Соблюдает ограничения частоты запросов API

4. Сторонние сервисы

Приложение интегрируется со следующими внешними сервисами, однако они не собирают персональные данные через наше приложение:

  • The Space Devs SNAPI — источник новостей о космосе
  • Google Play Services — для распространения и обновлений приложения (только Google Play)
