Privacy Policy

Last Updated: May 8, 2026

1. Information Collection

SpaceNews Explorer does not collect, store, or transmit any personal data. The app is designed with privacy as a fundamental principle.

  • No personal identification information collected
  • No location data tracking
  • No user behavior analytics
  • No cookies or tracking scripts

2. Data Processing

All data processing occurs locally on your device. The app uses the following local services:

  • Local Database: Favorite articles are stored in Room database on your device only
  • Offline Storage: Cached articles are saved locally for offline reading
  • Preferences: User settings (theme, etc.) stored in Android DataStore

3. API Data Usage

The app fetches space news from The Spaceflight News API (SNAPI) operated by The Space Devs. While the API processes public space news data, our app:

  • Does not modify API responses
  • Does not store user queries or search history
  • Does not link API requests to user identity
  • Respects API rate limits

4. Third-Party Services

The app integrates with the following external services, but they do not collect personal data through our application:

  • The Space Devs SNAPI - Data source for space news
  • Google Play Services - For app distribution and updates (Google Play only)
